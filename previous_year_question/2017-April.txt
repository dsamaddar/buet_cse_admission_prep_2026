8. What is the problem of using small page size in memory? What are its advantages?
Problems of using small page size:

Large page table – More pages are required for the same amount of memory, so the page table becomes larger.
More page-table overhead – More entries must be maintained and managed.
More TLB pressure – A fixed-size TLB can hold fewer total bytes of memory because each entry maps a smaller page.
More page faults may occur – A small page brings less data into memory at each page fault, potentially requiring more page transfers.

Advantages of small page size:

Less internal fragmentation – Unused space inside a page is smaller.
Better memory utilization – Memory can be allocated more precisely.
Less unnecessary data transfer – A page fault transfers a smaller amount of data.
Better process isolation/granularity – Memory can be managed at a finer granularity.

27. Define multitasking, multi programming, and multi threading?

Multiprogramming is a technique in which multiple programs are kept in main memory at the same time, and the CPU switches to another program when the current program is waiting for I/O.
Goal: Maximize CPU utilization.

Multitasking is an operating system technique in which multiple tasks/processes appear to execute simultaneously by rapidly switching the CPU among them.
Goal: Provide responsiveness and efficient CPU sharing.

Multithreading is the execution of multiple threads within a single process. Threads share the process's resources, such as memory and files, but have their own execution state.
Goal: Improve concurrency and responsiveness within a program.
