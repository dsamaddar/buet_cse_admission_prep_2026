2.implement max heap sort(algorithm)

Max Heap Sort

HEAPIFY(A, n, i)
    largest = i
    left = 2*i + 1
    right = 2*i + 2

    if left < n AND A[left] > A[largest]
        largest = left

    if right < n AND A[right] > A[largest]
        largest = right

    if largest != i
        swap(A[i], A[largest])
        HEAPIFY(A, n, largest)


HEAPSORT(A, n)
    // Build Max Heap
    for i = n/2 - 1 down to 0
        HEAPIFY(A, n, i)

    // Extract maximum one by one
    for i = n-1 down to 1
        swap(A[0], A[i])
        HEAPIFY(A, i, 0)

Time Complexity:

Build Max Heap: O(n)
Heap Sort: O(n log n)
Best/Average/Worst: O(n log n)

Space Complexity: O(1) auxiliary space.

Result: Max-Heap Sort produces the elements in ascending order.

3.why pentium is superscaler processor?
The Intel Pentium processor is called a superscalar processor because it has multiple execution pipelines 
and can execute more than one instruction simultaneously in a single clock cycle.The original Pentium had two integer pipelines, 
called the U-pipe and V-pipe. Under suitable conditions, two independent instructions could be issued and executed at the same time.

Therefore:

Superscalar → Multiple pipelines → Multiple instructions per clock cycle

4.advantages of microcontoller over microprocessor

Advantages of Microcontroller over Microprocessor

A microcontroller integrates the CPU, memory, I/O ports, timers, counters, and other peripherals on a single chip. Therefore, it has several advantages over a microprocessor:

Lower cost – Requires fewer external components.
Smaller size – Most required components are integrated into one chip.
Lower power consumption – Suitable for battery-operated and embedded systems.
Higher reliability – Fewer external connections/components reduce the chance of failure.
Simpler circuit design – Memory, I/O, timers, etc. are already integrated.
Faster for dedicated applications – Designed for specific control-oriented tasks.
Easy to interface – Built-in I/O ports and peripherals simplify interfacing with sensors and actuators.

Examples of applications: washing machines, traffic lights, remote controls, automobiles, and IoT devices.

using namespace std;

{

	int i = 0; 
	int j = 4; // last index

	{ 
		char temp = a[i];
